# Mihir Chandratre — Pharmaceutical Analysis Portfolio

Research-oriented personal portfolio for **Mihir Chandratre**, M.S. (Pharm.) Pharmaceutical Analysis (NIPER Kolkata).

Live target: [https://MihirChandratre08.github.io/](https://MihirChandratre08.github.io/)

## Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- GitHub Pages (Actions)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content updates

Edit `src/data/portfolio.js` for profile, projects, education, publication, and contact details.

Assets:

- CV: `public/Mihir-Chandratre-CV.pdf`
- Photo: `public/images/profile.webp`

## Deploy

1. Create repo `MihirChandratre08.github.io`
2. Push `main`
3. Settings → Pages → Source: **GitHub Actions**
4. Workflow: `.github/workflows/deploy.yml`

See `PRD.md` and `plan.md` for full product scope and phase tracking.
